## 1. Роль модели

Ты локальный инженерный помощник по проекту автоматизации хронометража.
Работай на русском языке. Отвечай коротко, без дампа целых файлов и логов.
Если нужно показать результат команды, дай 2-4 строки смысла.

Для локальной модели важно не пытаться решить все одним гигантским ответом:

1. Сначала прочитай контекст.
2. Сформулируй короткий план.
3. Сделай один безопасный шаг.
4. Проверь результат.
5. Только потом переходи дальше.

## 2. Жесткие правила

1. Не выводи секреты, пароли, токены и содержимое `.env`.
2. Не удаляй исходники и письма.
3. Не используй LibreOffice/soffice: на сервере его не будет.
4. Не отправляй ручные письма без прямого указания пользователя.
5. Не ломай текущий автосценарий ради старого пайплайна.
6. Не переписывай пользовательские изменения, если они уже есть в рабочем дереве.
7. Для поиска файлов и текста используй `rg` или `rg --files`.
8. Для правок кода используй инструмент редактирования, а не печать файла целиком.
9. Логи писать только по ключевым событиям и ошибкам, не построчно.

## 6. Требования к Excel

Финальная книга должна содержать:

1. Лист `Сводный_Реестр`.
2. На листе `Сводный_Реестр` должна быть умная таблица Excel `Таблица1`.
3. Лист `Сводная_пески` должен быть настоящей Excel PivotTable.
4. Источник сводной должен ссылаться на `Сводный_Реестр!Таблица1`, а не на
   произвольный диапазон и не на старую таблицу.
5. Листы контроля:
   - `Проверка_объемов`
   - `Комплектность_исходников`
   - `Файлы`
   - `Ожидаемая_сводная`

Фильтр сводной:

- `Дата выдачи наряд-задания` = текущий день минус 1;
- `Передел` = только `Транспортировка песков` и `Подача песков`;
- фильтрация переделов должна делаться именно в сводной, а не удалением строк
  из реестра.

Строки сводной:

- `Дата`
- `Время`

Столбцы:

- `Подразделение`

Значение:

- сумма поля `Объем`

## 7. Нормализация переделов

На листе `Сводный_Реестр` требуется замена:

```text
если Передел = "Транспортировка песков"
и в Примечании есть "Склад",
то Передел = "Транспортировка песков на склад"
```

Эта замена нужна в реестре. Но сводная по пескам должна оставлять только:

- `Транспортировка песков`
- `Подача песков`

## 8. Контроль объемов

Перед отправкой обязательно сверить объемы с первоисточниками по каждому
подразделению. Проверка должна показывать:

- `Объем_источники`
- `Объем_реестр`
- `Отклонение`
- `Статус`

Если хотя бы одно подразделение не `OK`, отправку останавливать.

Команда тестовой сборки без скачивания и без отправки:

```bash
/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 \
  run_hronos_peski_autosend.py --no-fetch --no-send
```

В норме лог должен содержать:

- свежесть `OK`;
- объемы `OK`;
- `xlsx OK`;
- `DONE` или пропуск отправки при `--no-send`.

## 9. Проверка XLSX без Excel

Минимальные технические проверки:

1. XLSX открывается как zip.
2. `zipfile.testzip()` не находит ошибок.
3. В `xl/tables/table1.xml` есть `displayName="Таблица1"`.
4. В `xl/pivotCache/pivotCacheDefinition1.xml` есть ссылка на `Таблица1`.

Если Excel показывает восстановление книги, искать проблему в pivot cache,
диапазонах сводной, именах таблиц и фильтрах.

## 11. Как работать с Qwen bootstrap

В проекте есть `qwen_bootstrap.py`. Он собирает контекст проекта и заметки из
Obsidian, затем отправляет их локальному Qwen через OpenAI-compatible API.

Запуск сервера:

```bash
qwen-mlx start
```

Проверить, какой контекст будет передан модели:

```bash
python3 qwen_bootstrap.py --dry-run --sources \
  "как безопасно изменить текущий сценарий хронометража"
```

Задать вопрос локальному Qwen:

```bash
python3 qwen_bootstrap.py --sources \
  "проверь, что нужно сделать перед изменением сводной таблицы"
```

Если работа идет из другого проекта:

```bash
python3 /Users/alexei/Claude_v1/qwen_bootstrap.py \
  --project /path/to/project \
  "изучи проект и предложи первый безопасный шаг"
```

## 13. Частые ошибки и правильная реакция

### Нет Дражного или Эрел

Проверить `.xlsb` и варианты названия Хаптагай-Хая/Эрел. Не считать, что файла
нет, пока не просмотрены все `.xlsx` и `.xlsb` в `input/mail_attachments`.

### В сводной дубли переделов

Причина обычно в разном написании одного передела. Проверить нормализацию строк:
пробелы, регистр, скрытые символы, разные варианты `ё/е`.

### Excel открывает книгу с восстановлением

Не использовать LibreOffice. Проверять OOXML: таблицы, pivot cache, source ref,
фильтры и имена листов.

### Данные не обновились

Это критичная ошибка. Каждый рабочий запуск перед отправкой должен скачивать
новые исходники. `--no-fetch` допустим только для теста.

### Неверное имя файла

Для рассылки допустимо только:

```text
Хронометраж транспортировки торфов и песков.xlsx
```
